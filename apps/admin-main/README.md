# User Dashboard

이 앱은 GitAnimals 관리자 화면이다. 화면 원본은
[Figma User Dashboard](https://www.figma.com/design/WKoig9rtmv5UpkF1CZuE34/User-Dashboard)에서
확인할 수 있다.

저장소 루트에서 의존성을 설치한 뒤 다음 명령을 사용한다.

```bash
pnpm install
pnpm --filter @gitanimals/admin-main dev
```

빌드·린트·타입 검사와 작업 조건은 [`AGENTS.md`](AGENTS.md)에 정리되어 있다.
